Installation

Ready in three steps.

The extension is installed manually because it is not published in the Chrome Web Store.

  1. 01

    Download and extract

    Download the ZIP above and extract it into a folder you plan to keep.

  2. 02

    Load the extension

    Open chrome://extensions, enable Developer mode, then choose Load unpacked. Select the extracted folder that directly contains manifest.json.

  3. 03

    Open PDC or SIS

    Use the calendar buttons on PDC enrollment pages, or Add class schedule on SIS My Class Schedule.
