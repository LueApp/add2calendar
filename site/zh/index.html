安装方法

三步开始使用。

扩展尚未上架 Chrome 应用商店，因此需要手动安装。

  1. 01

    下载并解压

    下载上方 ZIP 文件，将其解压到一个以后不会随意移动的文件夹。

  2. 02

    加载扩展

    打开 chrome://extensions，开启开发者模式，点击加载已解压的扩展程序。选择根目录中直接包含 manifest.json 的文件夹。

  3. 03

    打开 PDC 或 SIS

    使用 PDC 报名页面上的日历按钮，或 SIS My Class Schedule 页面上的 Add class schedule。

批量导出

把一周的活动都带走。

选择需要的活动、课程和场次，再生成一个整洁的日历文件。每条日程都会保留名称、时间、地点、讲者和来源链接。

  • ✓ 读取所有 PDC 报名分页
  • ✓ 导出 SIS 已选课程
  • ✓ 使用中国标准时间（UTC+08:00）
