# Add2Calendar v0.4.0

This release adds an advanced Outlook cleanup tool for arbitrary calendar events.

- Cleanup is disabled by default and must be activated manually from extension Settings.
- Users supply a Microsoft Entra application client ID and register the extension’s displayed redirect URL.
- Microsoft sign-in uses the authorization code flow with PKCE and delegated `Calendars.ReadWrite` permission.
- Users choose a writable calendar and date range, search events, and explicitly select entries.
- A final review warns about organizer meetings and recurring items and requires a confirmation checkbox.
- Deletions are sent to Microsoft Graph in batches of at most 20.
- The Microsoft access token remains only in the cleanup tab’s memory; attendee identities are discarded after meeting-risk classification.
- Deactivation removes the cleanup configuration and optional Microsoft host access.

Microsoft Entra setup and usage instructions are available in the English and Chinese README files.

此版本加入高级 Outlook 清理工具，可处理日历中的任意日程。

- 清理功能默认关闭，必须从扩展设置中手动启用。
- 用户需要提供 Microsoft Entra 应用程序客户端 ID，并登记扩展显示的重定向链接。
- Microsoft 登录采用带 PKCE 的授权码流程，并请求委托的 `Calendars.ReadWrite` 权限。
- 用户自行选择可写日历和日期范围，搜索日程并明确勾选条目。
- 最终检查会提示由用户组织的会议及周期性条目，并要求勾选确认框。
- 删除请求以每批最多 20 条的方式发送给 Microsoft Graph。
- Microsoft 访问令牌只保存在清理标签页内存中；参会人身份会在风险分类后立即丢弃。
- 停用功能会移除清理配置和可选的 Microsoft 主机访问权限。

Microsoft Entra 配置和使用步骤见中英文 README。
