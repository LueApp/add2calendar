# Add2Calendar v0.3.3

Add2Calendar now has a complete English and Simplified Chinese interface.

- The extension name and description follow Chrome’s UI language.
- PDC and SIS injected controls, settings, event previews, and batch previews are localized.
- Provider guidance, venue choices, validation errors, Nextcloud feedback, dates, and generated event descriptions are localized.
- English remains the fallback locale.

After updating, click **Reload** on Add2Calendar in `chrome://extensions`, then reload open PDC and SIS tabs. Chrome selects the language from its own interface language.

---

Add2Calendar 现在提供完整的英文和简体中文界面。

- 扩展名称和说明会跟随 Chrome 的界面语言。
- PDC 和 SIS 页面中的按钮、设置、单个日程预览及批量预览均已本地化。
- 日历服务说明、地点选择、验证错误、Nextcloud 反馈、日期和生成的日程说明均已翻译。
- 如果当前语言不受支持，则使用英文。

更新后，请在 `chrome://extensions` 中点击 Add2Calendar 的**重新加载**，再刷新已经打开的 PDC 和 SIS 标签页。Chrome 会根据自身的界面语言选择扩展语言。
