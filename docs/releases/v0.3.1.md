# Add2Calendar v0.3.1

This patch fixes **Add class schedule** remaining disabled on a fully loaded SIS timetable.

Add2Calendar now falls back to the visible SIS table when the page’s schedule API response is not observable. It reads only the Course, Section, Description, Status, Date & Time, Location, and Instructor columns, preserves separate recurring meeting patterns, and continues to exclude classes that are not marked Enrolled.

After updating, click **Reload** on Add2Calendar in `chrome://extensions`, then reload SIS **My Class Schedule**.

---

此补丁修复 SIS 课表已加载完成，但 **Add class schedule** 仍然不可用的问题。

当扩展无法观察到 SIS 的课表接口响应时，现在会改为读取页面上可见的课表。它只读取课程、班别、说明、状态、日期与时间、地点和教师列，保留不同的周期性上课安排，并继续排除未标记为 Enrolled 的课程。

更新后，请在 `chrome://extensions` 中点击 Add2Calendar 的**重新加载**，再刷新 SIS **My Class Schedule** 页面。
