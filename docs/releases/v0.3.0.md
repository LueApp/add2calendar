# Add2Calendar v0.3.0

Add2Calendar now supports both HKUST(GZ) PDC events and SIS class schedules.

- Adds an **Add class schedule** control to SIS **My Class Schedule**.
- Exports enrolled classes and recurring meetings while excluding waitlisted and dropped classes.
- Preserves course code, title, section, dates, weekdays, times, room, instructors, and SIS source link.
- Uses stable SIS-specific identifiers and China Standard Time (UTC+08:00).
- Observes the schedule response already loaded by SIS and discards student identifiers and authentication data before opening the preview.
- Retains individual and batch PDC export, Outlook, Google Calendar, Nextcloud, and `.ics` support.

**Install or update:** download `add2calendar-0.3.0.zip`, extract it, open `chrome://extensions`, enable Developer mode, and use **Load unpacked** to select the folder directly containing `manifest.json`. If updating an existing unpacked installation, replace the old files in the same folder and click **Reload**. Reload open PDC and SIS tabs afterward.

Add2Calendar 现在同时支持香港科技大学（广州）的 PDC 活动和 SIS 课程表。

- 在 SIS 的 **My Class Schedule（我的课表）**页面添加 **Add class schedule** 按钮。
- 导出已选课程和周期性上课时间，排除候补及已退课程。
- 保留课程编号、名称、班别、日期、星期、时间、教室、教师及 SIS 来源链接。
- 使用稳定的 SIS 专用标识，并按中国标准时间（UTC+08:00）处理。
- 只观察 SIS 页面原本加载的课表响应，在打开预览前丢弃学号及认证数据。
- 保留 PDC 单个及批量导出，以及 Outlook、Google 日历、Nextcloud 和 `.ics` 支持。

**安装或更新：** 下载 `add2calendar-0.3.0.zip` 并解压，打开 `chrome://extensions`，开启开发者模式，点击**加载已解压的扩展程序**，选择直接包含 `manifest.json` 的文件夹。更新已有的未打包安装时，请覆盖原文件并点击**重新加载**，随后刷新已经打开的 PDC 和 SIS 标签页。
