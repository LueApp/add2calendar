## English

PDC Calendar adds calendar buttons to HKUST(GZ) PDC enrollment pages. This release supports individual events and batch export across all enrollment pages.

- Outlook school/personal accounts and Google Calendar: prefilled single events or one `.ics` import for a batch.
- Nextcloud: direct additions after setup, with duplicate protection for identical sessions created by this extension.
- Multiple meeting dates, session selection, and China Standard Time conversion.
- English and Simplified Chinese installation guides and privacy documentation.

**Install:** download the attached `pdc-calendar-0.2.0.zip`, extract it, open `chrome://extensions`, enable Developer mode, and use Load unpacked to select the folder directly containing `manifest.json`. Reload PDC and sign in normally.

**Outlook batch:** Add multiple events → select sessions → Download for Outlook → Outlook Calendar → Add calendar → Upload from file → Import once.

Existing users should replace files in the same installation folder, then reload the extension and PDC. Added events are copies; later PDC changes are not synchronized. Repeated Outlook imports may create duplicates.

[English guide](https://github.com/LueApp/add2calendar/blob/main/README.md)

## 简体中文

PDC Calendar 为香港科技大学（广州）PDC 报名页面添加日历按钮。本版本支持单个活动添加，以及跨所有报名分页的批量导出。

- 学校／个人 Outlook 和 Google 日历：单个活动预填，或通过一个 `.ics` 文件批量导入。
- Nextcloud：配置后直接添加，并跳过此前由本扩展添加的相同场次。
- 支持多次会议、场次勾选和中国标准时间转换。
- 提供中英文安装指南及隐私说明。

**安装：** 下载附件 `pdc-calendar-0.2.0.zip` 并解压，打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的文件夹。随后刷新 PDC 并正常登录。

**Outlook 批量导入：** Add multiple events → 选择场次 → Download for Outlook → Outlook 日历 → 添加日历 → 从文件上传 → 一次导入。

已安装用户请将新文件覆盖到原安装文件夹，再重新加载扩展并刷新 PDC。添加的是活动副本，后续 PDC 变更不会自动同步；重复导入 Outlook 可能产生重复条目。

[中文指南](https://github.com/LueApp/add2calendar/blob/main/README.zh-CN.md)
