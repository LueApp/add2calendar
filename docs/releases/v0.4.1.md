# Add2Calendar v0.4.1

This patch adds tenant-specific Microsoft sign-in for single-tenant Entra applications.

- Outlook cleanup Settings now accept a Directory (tenant) ID.
- Single-tenant apps use `/{tenant-id}/oauth2/v2.0` for both authorization and token exchange.
- Multitenant apps can continue using `common`, `organizations`, or `consumers` as appropriate.
- Tenant authority values are validated before activation.
- Existing v0.4.0 cleanup configurations default to `common` until updated.

For AADSTS50194, copy **Directory (tenant) ID** from the Entra app Overview page, paste it into **Microsoft tenant authority**, and activate Outlook cleanup again.

---

此补丁为单租户 Entra 应用加入租户专用的 Microsoft 登录。

- Outlook 清理设置现在可以填写目录（租户）ID。
- 单租户应用会在授权和令牌交换时使用 `/{tenant-id}/oauth2/v2.0`。
- 多租户应用仍可按其账号类型使用 `common`、`organizations` 或 `consumers`。
- 启用前会验证租户颁发机构。
- 现有 v0.4.0 配置在更新前仍默认使用 `common`。

遇到 AADSTS50194 时，请从 Entra 应用概述页复制**目录（租户）ID**，填入 **Microsoft 租户颁发机构**，再重新启用 Outlook 清理。
