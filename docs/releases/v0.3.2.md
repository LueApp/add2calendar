# Add2Calendar v0.3.2

This patch improves SIS class identification and ambiguous venue handling.

- SIS titles now include the class section, for example `SYSH 5000 · T01 · Model-Based Systems Engineering`.
- When SIS lists different venues for the same class meeting, the session stays available and shows a warning.
- Each affected session lets you choose one listed venue or keep all venues combined.
- Source-neutral validation messages no longer refer to PDC while processing SIS data.

After updating, click **Reload** on Add2Calendar in `chrome://extensions`, then reload SIS **My Class Schedule**.

---

此补丁改善了 SIS 课程区分方式和地点冲突处理。

- SIS 日历标题现在包含班别，例如 `SYSH 5000 · T01 · Model-Based Systems Engineering`。
- 如果 SIS 为同一个上课时间列出不同地点，该场次会保留并显示提示。
- 每个受影响的场次都可以选择一个地点，或保留所有地点的组合。
- 处理 SIS 数据时，验证信息不会再错误地提到 PDC。

更新后，请在 `chrome://extensions` 中点击 Add2Calendar 的**重新加载**，再刷新 SIS **My Class Schedule** 页面。
